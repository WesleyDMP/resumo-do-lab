# resumo-do-lab
Este repositório contém o resumo do desenvolvimento do lab na DIO
Uso de redundância e infraestrutura distribuída para garantir a continuidade.

Capital Expenditure (CapEx) vs. Operational Expenditure (OpEx): A teoria de que a nuvem move o gasto de infraestrutura de capital (compra antecipada) para despesa operacional (pagamento pelo uso).

Modelos de Implantação:

Pública: Serviços oferecidos por terceiros na internet, acessíveis ao público.

Privada: Infraestrutura de nuvem operada exclusivamente por uma única organização.

Híbrida: Uma combinação das nuvens pública e privada.
